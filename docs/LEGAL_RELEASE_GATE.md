# Legal Release Gate / 法律合規發布門檻

**Policy:** Do not claim legal clearance or publish a public commercial release until all mandatory checks are documented and approved.

## Mandatory checklist
- [ ] Verify the exact Manim Community Edition version and both upstream MIT copyright/license notices; preserve verbatim copies when redistributing covered code.
- [ ] Generate and review an SBOM and license inventory for all direct and transitive Python and system dependencies, including FFmpeg, Cairo and Pango.
- [ ] Audit bundled fonts for redistribution and commercial-use rights.
- [ ] Confirm rights to the original Embodied Worker logo, including any generated or commissioned artwork; store approval evidence privately.
- [ ] Search relevant trademark registries and marketplaces for potential conflicts involving the EW Manim Draw product name; obtain counsel review if needed.
- [ ] Use no Manim or 3Blue1Brown marks, characters or protected illustrations without permission.
- [ ] Audit third-party source, templates, reference projects, screenshots, audio and sample videos for provenance and licenses.
- [ ] Review website, plugin manifest and promotional claims for accuracy; never imply official Manim affiliation.
- [ ] Publish accurate privacy policy, terms, support contact and data retention disclosures based on actual MCP/rendering infrastructure.
- [ ] Verify the applicable platform plugin submission requirements and perform security testing before public distribution.
- [ ] Record a dated release decision and responsible approver; seek qualified legal review for unresolved IP or trademark questions.

## Development constraints
Manim is a runtime dependency; use independently authored templates and declarative JSON. Do not run untrusted Python. Public source visibility does not by itself grant an open-source license to EW Manim Draw's original code.

## Approved public description
EW Manim Draw is an independent animation workflow tool developed by Embodied Worker, powered by the open-source Manim Community Edition. It is not affiliated with or endorsed by the Manim Community project.
