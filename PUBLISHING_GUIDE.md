# EW Manim Draw Publishing Guide / 發布指引

1. Verify plugin.json, SKILL.md and openai.yaml agree on name, version, capabilities and starter prompts.
2. Commit the owner-approved original logo binary as plugins/ew-manim-draw/assets/icon.png and the corresponding skill icon; the paths currently remain pending until the actual files are uploaded.
3. Validate the JSON schema and CLI using real flow cases including Traditional Chinese.
4. Run a genuine Manim preview and inspect rendered output before claiming MP4 support.
5. For MCP-enabled release, deploy and verify authenticated, isolated rendering with limits and evidence logs.
6. Check the public website, support, privacy and terms links are accessible without login.
7. Only after these checks, prepare submission metadata and request review. Do not represent draft plugin packaging as an installed or approved plugin.
